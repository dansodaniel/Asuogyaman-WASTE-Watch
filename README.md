# Asuogyaman-WASTE-Watch
AsuoClean GIS turns waste collection and sanitation records into an interactive hotspot map for Asuogyaman District, Ghana. Built with pandas, geopandas, and folium, it scores collection points by missed-pickup and overflow rates to flag problem areas at a glance. Runs on synthetic data for now, structured to plug in real field data.
